# Система турниров с AI-аналитикой

## Что добавлено

### 1. Полноценная система турниров

#### База данных
- 6 новых таблиц для хранения турниров, участников, истории и статистики
- Автоматическая миграция при запуске приложения

#### API Endpoints
- **Турниры**: CRUD операции, регистрация, таблица лидеров
- **AI-прогнозы**: Расчет вероятности победы на основе истории
- **Статистика**: Таблицы лучших игроков по HCP и победам
- **Флайты**: Загрузка результатов через фото

### 2. Интерфейс

#### Страница турниров (`/tournaments`)
- Список всех турниров с группировкой по месяцам
- Статусы: предстоящие, активные, завершенные
- Клик на турнир → переход к деталям

#### Страница детального просмотра (`/tournament/:id`)

**3 вкладки:**

1. **Таблица лидеров**
   - Текущие позиции участников
   - Счета и handicap
   - Обновление каждые 30 сек для активных турниров

2. **AI Прогнозы** (для активных/предстоящих турниров)
   - Вероятность победы каждого игрока
   - Уровень уверенности (высокий/средний/низкий)
   - Ключевые факторы
   - Объяснение прогноза

3. **Лучшие игроки**
   - ТОП-20 по Handicap Index
   - ТОП-20 по победам в турнирах

### 3. Telegram Bot - Админ панель

#### Команды

**Управление турнирами:**
- `/admin` - Главное меню
- `/create_tournament` - Создать турнир (пошаговый процесс)
- `/list_tournaments` - Список всех турниров
- `/activate_tournament <id>` - Активировать турнир
- `/complete_tournament <id>` - Завершить турнир

**Загрузка результатов:**
- `/upload_flight <tournament_id> <flight_number>` - Загрузить фото результатов флайта
- После команды просто отправьте фото скор-карты
- Бот автоматически распознает результаты и обновит таблицу

**Импорт данных:**
- `/import_history` - Загрузить исторические данные
- Отправьте JSON файл (см. `backend/example-history-import.json`)
- Система автоматически сопоставит игроков

**Статистика:**
- `/stats` - Общая статистика системы

### 4. AI-прогнозы на победу

Система анализирует для каждого игрока:
- Текущий Handicap Index
- Историю участия в турнирах (до 20 последних)
- Количество побед и попаданий в ТОП-3
- Недавнюю форму (последние 5 турниров)
- Текущий счет (если турнир активен)

Выдает:
- Вероятность победы (0-100%)
- Уровень уверенности
- Объяснение прогноза
- Ключевые факторы

### 5. Историческая база игроков

Даже если игрок не зарегистрирован в системе, его данные из старых турниров учитываются:
- Автоматическое сопоставление по имени
- Агрегированная статистика
- Учет в AI-прогнозах

## Настройка

### 1. Переменные окружения

Добавьте в `.env`:

```bash
# Telegram Admin IDs (ваш Telegram ID)
TELEGRAM_ADMIN_IDS=123456789,987654321

# Claude AI для прогнозов (опционально, если есть)
ANTHROPIC_API_KEY=your_key_here
```

Как узнать свой Telegram ID:
1. Напишите боту [@userinfobot](https://t.me/userinfobot)
2. Он пришлет ваш ID

### 2. База данных

Миграция запустится автоматически при старте приложения.

Проверить можно так:
```bash
psql -d your_database -c "SELECT COUNT(*) FROM tournaments"
```

### 3. Импорт исторических данных

1. Подготовьте JSON файл по образцу `backend/example-history-import.json`
2. Отправьте боту команду `/import_history`
3. Отправьте файл
4. Запустите пересчет статистики:
```bash
cd backend
npm run update-stats
```

## Workflow использования

### Создание турнира

**Через бота:**
1. `/create_tournament`
2. Введите название
3. Введите дату (YYYY-MM-DD)
4. Введите название поля
5. Турнир создан!

**Через API:**
```bash
curl -X POST http://localhost:3001/api/tournaments \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Летний кубок 2026",
    "start_date": "2026-07-15T10:00:00Z",
    "course_name": "Golf Club Minsk",
    "tier": "platinum",
    "holes_count": 18
  }'
```

### Регистрация игроков

Игроки регистрируются через мини-апп на странице турнира.

Или через API:
```bash
curl -X POST http://localhost:3001/api/tournaments/{id}/register \
  -H "Authorization: Bearer USER_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"handicap_index": 12.5, "flight_number": 1}'
```

### Запуск турнира

```bash
/activate_tournament <tournament_id>
```

Статус меняется на `active`, появляются AI-прогнозы.

### Загрузка результатов во время турнира

```bash
/upload_flight <tournament_id> 1
```

Затем отправьте фото скор-карты. Бот:
1. Распознает результаты
2. Сопоставит игроков по именам
3. Обновит счета
4. Пересчитает позиции
5. AI пересчитает прогнозы

### Завершение турнира

```bash
/complete_tournament <tournament_id>
```

Результаты:
- Сохраняются в историю игроков
- Обновляется статистика
- Турнир переходит в архив
