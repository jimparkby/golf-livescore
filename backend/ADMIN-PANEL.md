# Административная панель Telegram-бота

## Настройка доступа

### 1. Добавить админов в .env

Откройте файл `.env` и добавьте Telegram ID админов:

```env
ADMIN_TELEGRAM_IDS=123456789,987654321
```

**Как узнать свой Telegram ID:**
1. Откройте бота [@userinfobot](https://t.me/userinfobot)
2. Отправьте `/start`
3. Скопируйте ваш `Id` (например: `123456789`)

### 2. Создать таблицы в базе данных

Выполните SQL-миграцию:

```bash
psql -h your-db-host -U your-db-user -d your_db_name -f backend/migrations-admin.sql
```

Или подключитесь к базе данных и выполните содержимое файла `migrations-admin.sql`.

### 3. Перезапустить бота

```bash
# Если используете pm2
pm2 restart backend

# Или просто перезапустите Node.js процесс
```

## Использование

### Команды админа

#### `/admin`
Открывает главное меню административной панели с опциями:

- **📊 Ввести результаты турнира** - добавление результатов завершенных турниров
- **👥 Ввести участников** - добавление игроков в базу данных

### 1. Ввести результаты турнира

**Шаги:**
1. Отправьте `/admin`
2. Нажмите "📊 Ввести результаты турнира"
3. Выберите турнир из списка
4. Отправьте результаты в формате CSV:

```
Место,Имя игрока,Счет
```

**Пример:**
```
1,Иванов Иван,72
2,Петров Петр,74
3,Сидоров Сидор,75
4,Козлов Павел,76
5,Новиков Сергей,78
```

**Возможности:**
- ✅ Можно отправлять несколько строк за раз
- ✅ Автоматическое обновление при повторном вводе (по номеру места)
- ✅ Результаты сохраняются в таблицу `tournament_results`

### 2. Ввести участников

**Шаги:**
1. Отправьте `/admin`
2. Нажмите "👥 Ввести участников"
3. Отправьте данные участников в формате CSV:

```
Имя,Email,Телефон,Handicap
```

**Пример:**
```
Иванов Иван,ivan@example.com,+375291234567,12.5
Петров Петр,petr@example.com,+375297654321,18.0
Сидоров Сидор,,+375333456789,24.5
Козлов Павел,kozlov@example.com,,15.0
```

**Примечания:**
- Email и телефон необязательны (можно оставить пустым между запятыми)
- Handicap по умолчанию = 0.0
- При совпадении email существующий участник обновляется

**Возможности:**
- ✅ Массовый импорт участников
- ✅ Автоматическое обновление при совпадении email
- ✅ Данные сохраняются в таблицу `participants`

## Таблицы базы данных

### `tournaments`
Список турниров
- `id` - уникальный идентификатор
- `name` - название турнира
- `date` - дата проведения
- `location` - место проведения
- `description` - описание

### `tournament_results`
Результаты турниров
- `id` - уникальный идентификатор
- `tournament_id` - ссылка на турнир
- `place` - место игрока
- `player_name` - имя игрока
- `score` - счет
- `created_at`, `updated_at` - временные метки

### `participants`
База игроков
- `id` - уникальный идентификатор
- `name` - имя игрока
- `email` - электронная почта (уникальная)
- `phone` - телефон
- `handicap` - гандикап
- `created_at`, `updated_at` - временные метки

## Безопасность

- ✅ Доступ только по Telegram ID из переменной окружения
- ✅ Проверка прав доступа на каждое действие
- ✅ Callback queries защищены от неавторизованного доступа
- ✅ Сессии хранятся только в памяти (очищаются при перезапуске)

## Устранение неполадок

### Бот не отвечает на `/admin`
1. Проверьте, что ваш Telegram ID добавлен в `ADMIN_TELEGRAM_IDS`
2. Убедитесь, что бот перезапущен после изменения `.env`
3. Проверьте логи: `pm2 logs backend` или `docker logs <container>`

### Ошибка при сохранении результатов
1. Убедитесь, что таблицы созданы: `\dt` в psql
2. Проверьте формат данных (запятые, правильные типы)
3. Убедитесь, что турнир существует в таблице `tournaments`

### Как добавить турниры вручную
```sql
INSERT INTO tournaments (name, date, location)
VALUES ('Название турнира', '2026-12-31', 'Golf Club Minsk');
```
